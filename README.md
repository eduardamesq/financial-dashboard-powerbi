# Dashboard Financeiro em Power BI

Projeto de análise financeira desenvolvido em Power BI com foco no acompanhamento de indicadores estratégicos e movimentações bancárias.

## Funcionalidades
- Análise de recebimentos
- Controle de custos e impostos
- Visualização de lucro e margem
- Comparativo mensal
- Indicadores de movimentações via PIX
- Visualização por instituições bancárias

## Tecnologias utilizadas
- Power BI
- Excel
- DAX

## Objetivo
Transformar dados financeiros em visualizações intuitivas para auxiliar na tomada de decisões estratégicas.
